Adzuna API

Broad aggregator sweep (Austin / Dallas / Houston + remote). Register free at developer.adzuna.com, then paste your keys here. Free tier is ~1,000 calls/month; each refresh uses about one call per query × location.

Separate locations with semicolons. A remote sweep runs automatically on top.

Home

Where you live. Postings in your metro get the location class home; other metros in your state get home_state; the rest is remote-US / other-US / non-US. Drives the location filters, the scoring points in skills.yaml, the fit gate and the Adzuna sweeps. Applies from the next Refresh (existing rows reclassify on Rescore).

Role preset

A preset is a complete config/skills.yaml: which titles are fetched at all, the search terms for keyword-only boards, scoring weights, and the starting fit rules. Loading one replaces skills.yaml (a timestamped backup is kept) and rescores; the fetch rules apply from the next Refresh. Edit skills.yaml by hand for anything finer.

Location filters

What gets kept at fetch time. Applies from the next Refresh.

Refresh schedule

Nothing runs unless the server is up (python server.py). At each listed clock time (your PC's local time) the running server refreshes every source and posts the Discord digest if enabled; the Jobs page shows the next run next to the Refresh button. A time that passes while the server is down is skipped, not run late. Takes effect within a minute of saving, no restart.

Fit scoring (model)

The keyword score is a prefilter. Jobs at or above the gate are sent, ten at a time, to a cheap Claude model through your subscription (claude -p, no API key) together with resume/skills-inventory.md, preferences.md and the judgement rules in resume/fit-profile.md. Each job gets a fit 0-100, a reason and its gaps. Thumbs on the Jobs page accumulate as feedback; after N items a stronger model rewrites the profile rules and the affected jobs re-score. Answers you give while tailoring sharpen it too.

Resume tailoring

    
The ✎ Tailor resumes button runs the tailor-resume
      Claude Code skill in the background using your Claude subscription (no API key). One job at a
      time; each takes a few minutes. Output: <folder>\<Company>\<Role>\<jobId>\Tailored_Resume.docx

Apply pipeline

    
Plans read each job's real application form (Greenhouse / Ashby APIs, Lever page) and
      map every field to a value from resume/profile.yaml, your Q&A answers and the
      generated files. Nothing is submitted without your approval; the filler (next stage) runs only on approved plans.

    

      
      
    

    

      
      
      
    

    

      
    

    

      
      
      
      
    

    
Queued plans are filled by the /apply-queue skill running in a Claude session with the
      Chrome extension (on demand, or from a scheduled task). It never solves captchas, never creates accounts, and in
      prefill mode never clicks Submit.

    

      
      
    

  


  

    
Notifications

    
After every refresh, the new postings that clear the score bar are posted to a Discord channel
      as one message (best first, with links). Create a webhook in Discord: channel settings → Integrations →
      Webhooks → New webhook → Copy URL. The URL is a secret and is stored in config/local.yaml only.
