# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive; no harassment, personal attacks, or publishing of
others' private information. This matters doubly here because the tool handles people's
job-search data — never post anyone's resume, profile, or application details in an issue or
PR, including your own.

Reports go to the maintainer by email (see the GitHub profile of @vikaspalakurthi). Reports
are handled privately. Maintainers may remove, edit, or reject contributions and comments
that don't follow this code, and may ban repeat offenders.

The Contributor Covenant is available under CC BY 4.0 at
https://www.contributor-covenant.org.
